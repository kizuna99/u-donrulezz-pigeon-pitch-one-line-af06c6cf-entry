A tiny program that writes exactly one line to `/output/entry.txt` — a
city pigeon's elevator pitch for **NestEgg, Airbnb for window ledges**:
40 million listings, no mortgages, tenants who poop on the product, and a
seed round that is quite literally seeds. The line was drafted with an
OpenCode free-model round, then won a criteria-ordered tournament against
the judge's published criteria (a real pitch to investors, a joke that
lands, original, unmistakably pigeon-voiced, tight within 200 characters),
beating the PigeonAir delivery pitch and the post-crumb fleet line.
Output is byte-exact: 186 characters, 188 UTF-8 bytes, no trailing
newline. Run it with `python3 main.py`.
